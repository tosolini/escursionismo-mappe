# Contributing

Thanks for your interest in improving Escursionismo Mappe.

## Development Setup

1. Use a local WordPress environment.
2. Place this plugin in wp-content/plugins/escursionismo-mappe.
3. Activate the plugin from WordPress admin.

## Branching

- Create a feature branch from main.
- Keep changes focused and atomic.
- Use clear commit messages.

## Coding Guidelines

- Follow WordPress PHP coding standards where practical.
- Escape output and sanitize input.
- Keep backward compatibility for shortcodes and REST endpoints unless a breaking change is required.

## Pull Requests

Before opening a PR:
- Run PHP syntax checks.
- Run JavaScript syntax checks.
- Update README.md if behavior changes.
- Add a CHANGELOG.md entry under Unreleased.

## Bug Reports

Open an issue with:
- Environment details (WordPress, PHP, browser)
- Reproduction steps
- Expected vs actual behavior
- Screenshots/logs when relevant
