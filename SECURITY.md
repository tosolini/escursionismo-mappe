# Security Policy

## Supported Versions

Security fixes are currently provided for the latest release on the default branch.

## Reporting a Vulnerability

Please do not open public GitHub issues for security reports.

Send a private report to: security@tosolini.info

Include:
- A clear description of the issue
- Steps to reproduce
- Impact assessment
- Suggested fix (if available)

You will receive an acknowledgment within 3 business days.

## Disclosure Policy

- We investigate and validate reports before disclosure.
- We coordinate a fix and release timeline with the reporter when possible.
- We publish security notes in CHANGELOG.md after a patch is released.
